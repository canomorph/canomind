# CanoMind
Tauri 2 + React + TypeScript + Vite.

    npm install
    npm run tauri dev

Shortcuts: Tab subtopic · Enter sibling · F2 / double-click edit · Del · Ctrl+Z/Y · Ctrl+C/X/V/D · Ctrl+A · Ctrl+S · arrows nudge (Shift = 10px) · Esc.
Layout follows the Visio window: shapes panel, ribbon groups, rulers, page tabs, scrollbars. Files = tabs in the title bar, pages = tabs at the bottom.
Insert > Shapes: click a shape, then click (default size) or drag (custom size) on the canvas.
Icons: built-in inline set (src/icons.ts); Settings > Icon folder loads "<folder>/<name>.svg" first.
